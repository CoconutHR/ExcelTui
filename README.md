# Excel Tui

Excel 通用数据处理工具，提供丰富的 TUI 交互界面，支持数据提取、去重、筛选、合并、分割、JSONL 转换等常用操作。所有读写均使用文本格式，避免长数字被转为科学计数法。

## 安装

```bash
git clone https://github.com/CoconutHR/ExcelTui.git
cd ExcelTui
pip install .
```

安装完成后可以删除克隆的仓库文件夹，`exceltui` 命令仍然可用。如需更新版本，重新克隆并安装即可。

如果你是开发者，希望修改代码后立即生效，可以使用可编辑安装（此时不能删除仓库文件夹）：

```bash
pip install -e .
```

依赖：Python >= 3.7、openpyxl、rich。

## 使用

在任意目录下运行：

```bash
exceltui
```

工具会自动扫描当前目录下的 Excel / JSONL 文件，通过交互式菜单选择功能。

## 功能一览

| 编号 | 功能 | 说明 |
|------|------|------|
| 1 | Excel 通用数据提取 | 支持 JSON、键值对 `{key:value}`、纯文本三种格式，多列交互式处理，自定义输出格式，转义字符处理 |
| 2 | 去除指定列的重复项 | 选择列字母（A、B、AA 等），自动去重并输出统计，生成 `原文件名_去重_列.xlsx` |
| 3 | 筛选交集 | 选择数据文件与筛选文件，支持「保留交集」或「删除交集」两种模式，分别生成 `_筛选结果.xlsx` 或 `_排除结果.xlsx` |
| 4 | 合并当前文件夹下所有 Excel | 一键将当前目录全部 `.xlsx` 纵向合并为一个文件 |
| 5 | 按指定行数分割 Excel | 输入每份行数，自动拆分为多个文件 |
| 6 | 按主键横向合并两个 Excel | 选择主文件与追加文件，指定主键列，横向拼接 |
| 7 | 分组排序并标红最新时间行 | 按分组列 + 时间列排序，每组最新行标红高亮 |
| 8 | JSONL 解析为 Excel | 将 `.jsonl` 文件逐行解析，第一层键名作为表头，自动列宽，行高 14 |
| 9 | 退出程序 | — |

## 交互细节

所有文件选择提示支持直接按回车返回上级菜单（等同于输入 `q`），无需额外操作。当目录下没有匹配文件时，会暂停提示用户确认后再返回。
